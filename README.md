 Hand Gesture Recognition — Python & Computer Vision

Présentation

Projet de reconnaissance des gestes de la main à l'aide de techniques de vision par ordinateur et d'intelligence artificielle.

L'objectif est de développer un système capable d'identifier différents gestes à partir d'une webcam.

Technologies utilisées

- Python
- OpenCV
- YOLO
- Vision par ordinateur
- Ubuntu

Gestes étudiés

- HELP : demande d'aide
- OK : confirmation
- STOP : arrêt
- LEFT : direction gauche
- RIGHT : direction droite
- NONE : absence de geste reconnu

Travaux réalisés

- Constitution et préparation d'un dataset de gestes.
- Expérimentation de modèles de reconnaissance.
- Développement d'une application Python utilisant la webcam.
- Tests de reconnaissance en temps réel.
- Amélioration de la stabilité des prédictions.

Organisation du projet

- "main_v3.py" : version développée de l'application.
- "main_working.py" : version de travail.
- "capture.py" : acquisition des images.
- "prepare.py" : préparation des données.
- "test_yolo.py" : tests avec YOLO.
- "requirements.txt" : dépendances Python.
- "resultat.jpg" : illustration du résultat.

Remarque

Les datasets et les poids des modèles entraînés ne sont pas inclus dans ce dépôt. Leur absence peut empêcher l'exécution directe de certaines versions du programme.

Compétences développées

Programmation Python, vision par ordinateur, préparation de données, reconnaissance de gestes et expérimentation de modèles d'intelligence artificielle.

Projet personnel réalisé dans un environnement de développement Ubuntu.
